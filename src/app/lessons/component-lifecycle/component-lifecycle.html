ما هو Component Lifecycle؟

هو سلسلة من المراحل (Hooks) التي يمر بها الـ Component من لحظة إنشائه ➜ عرضه ➜ تحديثه ➜ تدميره. Angular يوفّر Lifecycle Hooks نقدر نستخدمها علشان ننفّذ كود في توقيتات محددة.

ترتيب الـ Lifecycle Hooks

constructor
↓
ngOnChanges
↓
ngOnInit
↓
ngDoCheck
↓
ngAfterContentInit
↓
ngAfterContentChecked
↓
ngAfterViewInit
↓
ngAfterViewChecked
↓
ngOnDestroy

1️⃣ constructor

📌 أول شيء يتم تنفيذه تهيئة المتغيرات حقن الـ Services (Dependency Injection)

❌ لا يُفضّل وضع API Calls هنا


2️⃣ ngOnChanges

📌 يُنفّذ عند تغيّر أي @Input() يعمل حتى قبل ngOnInit يستقبل التغييرات الجديدة والقديمة

📍 يُستخدم عند: مراقبة تغييرات البيانات القادمة من Parent


3️⃣ ngOnInit ⭐ (الأهم)

📌 يُنفّذ مرة واحدة فقط تحميل البيانات استدعاء API تهيئة القيم

✅ أفضل مكان لأي منطق أساسي


4️⃣ ngDoCheck

📌 يُنفّذ مع كل Change Detection للمراقبة اليدوية

❌ استخدامه بحذر (مكلف في الأداء)


5️⃣ ngAfterContentInit

📌 بعد تحميل ng-content


6️⃣ ngAfterContentChecked

📌 بعد كل فحص لمحتوى ng-content


7️⃣ ngAfterViewInit ⭐

📌 بعد تحميل الـ View + ViewChild أفضل مكان لاستخدام @ViewChild


8️⃣ ngAfterViewChecked

📌 بعد كل فحص للـ View

❌ لا تضع منطق ثقيل هنا


9️⃣ ngOnDestroy ⭐

📌 قبل تدمير الـ Component إلغاء الاشتراكات تنظيف الـ timers منع Memory Leak
