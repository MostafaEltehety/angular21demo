What is the Directive?

Sol:

A directive is a class with a @ Directive() decorator that Angular uses to manipulate the DOM.

“When this element appears, do something special.”

Types of Angular Directives :-

  1. Component Directives
  2. Structural Directives
  3. Attribute Directives

1) Component Directives

Used with a template. This type of directive is the most common directive type.

📌 Every Angular component is a directive.

2) Structural Directives

Change the DOM layout by adding and removing DOM elements.

Usually start with *
  • *ngIf
  • *ngFor
  • *ngSwitch
✔ Adds or removes elements from the DOM.

To use *ngIf must import NgIf from @angular/common

Welcome back!



3) Attribute Directives

Change the appearance or behavior of an element, component, or another directive.

Do not add/remove elements

  • ngClass
  • ngStyle
  • Custom Directives
