ما هو الـ Observable ؟

المشكلة بدون Observable

المشكلة بدون Observable تخيل: عندك API البيانات مش بتيجي فورًا ممكن: تيجي بعد شوية تيجي أكتر من مرة يحصل Error العملية تفضل شغالة (WebSocket – Timer) ❌ Promise تقدر ترجع قيمة واحدة فقط

✅ Observable تقدر ترجع 0 أو أكتر من قيمة على مدار الوقت

🔹 تعريف بسيط Observable = مصدر بيانات بيتابع الزمن ويقدر: يبعث Data يبعث Error يعلن إنه خلص (Complete)

🔹 مثال تشبيهي بسيط

قناة تلفزيون Observable البرامج Data الريموت Subscription تقفل التلفزيون Unsubscribe

🔹 Observable vs Promise

Promise

قيمة واحدة - يبدأ فورًا - لا يمكن الإلغاء - بسيط

Observable

قيم متعددة - يبدأ عند subscribe - يمكن الإلغاء - أقوى وأعمق

مكونات Observable الأساسية

observer.next(value); // يبعث قيمة

observer.error(error); // يبعث خطأ

observer.complete(); // ينهي البث

subscribe()

الـ subscribe هو اللي: يبدأ الـ Observable يستقبل القيم
