ما هو ng-template؟

هو قالب (Template) لا يظهر في الصفحة لوحده يتم عرضه باستخدام: *ngIf *ngFor ngTemplateOutlet أو من Component Logic

تمرير بيانات إلى ng-template

🧠 الفكرة الأساسية

ng-template = دالة context = parameters let-xxx = arguments

عرض Template يدويًا بـ ngTemplateOutlet

Name : {{name}}

Age : {{age}}

Score : {{score}}

Role : {{role}}

خلاصة ذهبية 🏆

ng-template = قالب

ngTemplateOutlet = عرض القالب

context = البيانات

$implicit = القيمة الافتراضية

let-xxx = استقبال البيانات
